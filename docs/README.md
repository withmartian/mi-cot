# Documentation

Project documentation, method descriptions, and methodology papers.

## Structure

- **methods/** - Detailed method descriptions
- **setup/** - Setup and installation guides
- **api/** - API reference documentation
- **figures/** - Figures and diagrams for documentation

## Writing Guidelines

- Use Markdown format
- Include code examples where applicable
- Link to relevant paper sections
- Keep separate from experiment results (use `../results/` for those)
